# Lil Dycey Artist Portfolio

An accessible, dependency-free one-page artist portfolio built with semantic HTML and CSS.

## Run locally

Open `index.html` directly in a browser, or serve the directory with any static file server:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

- Replace the placeholder copy, dates, venues, email address, social links, and canonical URL in `index.html`.
- Update the Open Graph image and the `Person` JSON-LD values when real artist information is available.
- Replace the CSS-generated artwork with optimized local images when artwork assets are supplied. Give every meaningful image concise, descriptive alt text.
- Keep the section IDs (`about`, `career`, and `shows`) unchanged unless the navigation links are updated too.
